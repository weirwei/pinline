# Pinline

给 Chrome 原生垂直标签栏补上 Arc 式的 Fav、Pin 和快捷键。界面仍是 Chrome 原生的，插件只改行为。

```
[ ✉ ][ 📅 ][ G ]      ← Fav：原生固定标签（图标方块），每个窗口都有
P  GitHub             ← Pin：普通整行标签，带标题
P  文档
──────────────        ← 分割线（一个特殊标签）
普通标签…
```

## 功能

- **Fav**：右键原生「固定」= 设为 Fav。所有窗口（包括新开的）都会有同一组 Fav，其他窗口里的是休眠副本。右键「取消固定」= 所有窗口一起删除，当前这个标签变回普通标签。拖动 Fav 方块排序，所有窗口同步。
- **Pin**：拖到分割线上方 = 设为 Pin，拖到下方 = 取消。也可以用右键菜单「设为 Pin / 取消 Pin」。
- **持久**：关掉 Fav / Pin 不会消失，会在原位置休眠重建：只是一个显示标题和图标的占位页，网站本身不加载；切过去才打开固定网址。
- **重启恢复**：Fav / Pin 存在 `chrome.storage.local` 和收藏夹里，重启后自动重新绑定、补齐。
- **Pin 分组**：Pin 区里的分组就是 Chrome 原生标签组。右键 Pin →「添加到新组」就建好一个分组；拖进 / 拖出组 = 加入 / 离开；在标签组上改名、改颜色、折叠都会记住。关闭组里的 Pin 会在组里原位休眠重建；切换 Space、重新加载插件后分组照样恢复。组里最后一个 Pin 移出后分组自动删除。切换 Space 时默认会把目标 Space 的分组全部收起（当前选中的标签所在的组除外，Chrome 不允许收起它），可在面板 Space 卡片里关掉。只有一层，不能嵌套。
- **重命名 Fav / Pin**：右键 →「重命名 Fav / Pin…」或在面板「Fav / Pin 名称」里改（按 Fav、当前 Space、Pin 分组排成可折叠的树），留空恢复网页原标题。名字会同步成书签标题（在书签管理器里改书签名也会改名）。休眠时直接显示新名字；已加载的网页需要一次「所有网站」权限（第一次改名时询问，只在改过名的网站上注入脚本，网站自己改标题也会被改回来），不授权时名字只在休眠时显示。
- **复制网址**（Arc 的 ⌘⇧C）：快捷键「复制当前页面网址」，休眠标签复制的是真实网址，成功后工具栏图标闪 ✓。Chrome 不让插件默认占用 ⌘⇧C（和「检查元素」冲突），需在 `chrome://extensions/shortcuts` 手动绑定。
- **分割线**：被关掉会自动重建；从 Fav / Pin 里打开的新链接会放到分割线下方。
- **分割线 = 控制面板**：点一下分割线，右边显示 Pinline 面板：Space 列表（点一下 / 按 1–9 只是选中；点「切换」、双击或回车才切过去）、新建 Space（直接输入名字）、重命名 / 删除选中的 Space（隐藏的也行，不用先切过去）、从收藏夹导入、快捷键一览。Chrome 自己选中分割线时（切换 Space 后、关掉旁边的标签后）会自动跳回正常标签。
- **Space**：每个 Space 有自己的 Pin 和标签，Fav 所有 Space 共用。分割线显示当前 Space 名（`── 工作 ────`，只有一个 Space 时只显示线）。切走时当前 Space 的标签会被记下网址并关闭，切回来时以休眠状态重新打开（只有之前选中的那个会加载），没有隐藏窗口。
- **收藏夹双向同步**：Fav 和 Pin 存在「其他书签 / Pinline」里（`⭐ Fav` 一个文件夹，每个 Space 一个文件夹，Pin 分组是 Space 文件夹里的子文件夹）。在书签管理器里改文件夹名 = 改 Space 名，拖动书签 = 调整顺序，加 / 删书签 = 加 / 删 Pin，把书签从 `⭐ Fav` 拖进某个 Space 文件夹 = Fav 变 Pin。反过来插件里的改动也会写回收藏夹。跨设备同步走 Chrome 自己的书签同步；新装插件时如果已有 Pinline 文件夹，会直接沿用。
- **从收藏夹导入 Space**：面板里「收藏夹」一栏，选一个书签文件夹，它直接包含的书签会变成新 Space 的 Pin，第一层子文件夹变成 Pin 分组，更深的文件夹按顺序打平到所在的分组里（原文件夹不动）。
- **自动归档**（Arc 的 Today 标签自动归档）：面板「归档」里选 关闭 / 12 小时 / 24 小时 / 7 天 / 30 天，默认关闭。超过这个时间没被选中过的普通标签会被关掉，记进归档列表（网址、标题、图标、所属 Space、归档时间）。每 15 分钟检查一次（`chrome.alarms`）。不会自动归档：Fav、Pin、分割线、每个窗口当前选中的标签、正在播放声音的标签、在标签组里的标签（标签组是你特意整理的，当作要留着）。隐藏 Space 里存着的标签也按它们最后一次被使用的时间过期，进归档。
- **归档列表**：面板里按时间倒序，可搜索标题 / 网址；点一条在当前窗口的分割线下方重新打开（同时从归档里移除），× 删除一条，「清空」删除全部。最多保留 500 条，超出时丢掉最旧的。
- **清空未固定标签**（Arc 的 ⌘⇧K）：快捷键「归档分割线下方的所有标签」、右键菜单或面板按钮。当前窗口分割线下方的所有普通标签都进归档（不管选中、播放声音、标签组），Fav / Pin 不动；如果选中的标签也被归档，会先打开一个新标签停在那里。和自动归档的设置无关，关闭时也能用。
- **最近使用的标签**（Arc 的 Ctrl+Tab）：快捷键「切到上一个最近使用的标签」。每个窗口按最近使用排序（不含分割线）；1.5 秒内连按会继续往更早的标签走（像 Alt-Tab，走到头回到起点），停下后落脚的标签才排到最前。顺序存在 `chrome.storage.session`，Service Worker 重启后还在，浏览器重启后清空。
- **在 [Arc Cmdbar](../arc-cmdbar/) 里用**：同时装了 Arc Cmdbar 时，它的搜索框里能搜到并执行 Pinline 的命令（Fav / Pin、回到 / 设为固定网址、重命名、Space 切换和新建、面板、清空未固定标签、最近使用的标签），每个其他 Space 一条「切到 Space：名字」，归档列表里的标签也能直接搜到、回车重新打开。休眠的 Fav / Pin 在命令栏里显示真实网址和名字，分割线不显示。接口是 `chrome.runtime.onMessageExternal`，只接受 Arc Cmdbar 的 id（manifest 的 `externally_connectable` 也只放行它）。
- **右键菜单**：设为/取消 Fav、设为/取消 Pin、回到固定网址、把当前网址设为固定网址、新建 Space、切到下一个 Space、归档分割线下方的所有标签、打开 Pinline 面板。

## 快捷键

默认都不绑定，在 `chrome://extensions/shortcuts` 里自己设：切换 Fav、切换 Pin、回到固定网址、设为固定网址、跳到第 1–9 个 Fav、跳到第 1–9 个 Pin、上一个 / 下一个 / 新建 Space、打开 Pinline 面板、归档分割线下方的所有标签、切到上一个最近使用的标签。

触控板手势切 Space：插件收不到手势，可以用 BetterTouchTool / Hammerspoon 把手势映射到「上一个 / 下一个 Space」快捷键。

## 安装（开发版）

1. 打开 `chrome://extensions`，开启右上角「开发者模式」。
2. 「加载已解压的扩展程序」→ 选择本目录。
3. 右键标签栏空白处 →「垂直显示标签」。

## 开发

```bash
npm test                                   # 单元测试（模拟 chrome API）
CHROME_BIN="/path/to/Google Chrome for Testing" npm run e2e   # 真浏览器端到端（含改名：用一份预授权所有网站的临时副本）
npm run zip                                # 打包上架用的 zip（自动去掉 manifest 的 key）
CHROME_HEADLESS="/path/to/chrome-headless-shell" npm run icons  # 从 icons/icon.svg 重新生成 PNG 图标
```

商店要填的说明和权限用途见 `store/listing.md`。

正式版 Chrome 不支持 `--load-extension`，e2e 需要 [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/)。

## 已知限制

- 插件无法修改原生标签栏界面：Fav 方块的大小/排列、分割线的样式都由 Chrome 决定。
- 分割线是一个真标签：悬停有关闭按钮、占 Cmd+1–9 的一个序号；用 Ctrl+Tab 逐个切换时会经过它（显示面板）。
- 关闭是「关掉后立即重建」，不是阻止关闭。
- 改了某个 Fav 的固定网址后，其他窗口里已有的休眠副本仍指向旧网址，直到它们被重建。
- 隐身窗口不处理。
- `chrome://`、Chrome 应用商店等页面不允许注入脚本，这些 Fav / Pin 的新名字只在休眠时显示。
- Chrome 会把标签组记成「已保存的标签组」。实测（Chrome for Testing 156、未登录）不会出现重复的组，但每切换一次 Space，Chrome 内部会多留下约 1 条（约 250 字节）已失效的标签记录；Chrome 会不会自动清理、登录账号后会不会同步出去，未验证。
- 切回一个 Space 时网页是重新打开的：滚动位置、表单输入、视频进度、登录前的临时状态都不会保留；标签组也不会保留。
- 同一个 Space 在多个窗口同时显示时只做了基本处理。
- 在收藏夹里删掉整个 Space 文件夹或 `⭐ Fav` 文件夹不会删除 Space / Fav，文件夹会被重建（删 Space 请用「管理 Space」）。Space 文件夹里第二层以下的子文件夹会被忽略。
- 普通标签（非 Pin）不进收藏夹；隐藏 Space 的标签只存在本机。
- 自动归档靠「最后一次被选中的时间」：插件自己记录（存在 `chrome.storage.local`，按标签 id）；浏览器重启后标签 id 会变，这时改用 Chrome 的 `Tab.lastAccessed`，没有的话从现在开始计时。重启后 `lastAccessed` 是不是还保留重启前的时间，未验证（实测一个从没选中过的新标签，`lastAccessed` 是它的创建时间）。
- 自动归档是定时检查，不是精确到点：最多晚 15 分钟。电脑睡眠期间不检查，醒来后的第一次检查会把超时的一次归档掉。
- 隐藏 Space 的标签按切走那一刻记下的使用时间过期；之前版本存下的、没有时间的标签，从第一次检查开始计时。
- 归档只存网址和标题：重新打开就是重新加载，滚动位置、表单、登录前的临时状态不会恢复。归档列表只在本机，不同步。
- 「最近使用的标签」连按途中经过的休眠标签会被唤醒（网页开始加载）。Chrome 自带的 Ctrl+Tab 仍是按位置切换，插件改不了；扩展快捷键也不支持 Tab 键，只能绑别的组合（如 Alt+Q）。
- manifest 里写了固定的 `key`，本地加载的开发版 id 固定为 `ebdnmlhdkdijlgjlmnpjjnkejcgonjke`（Arc Cmdbar 靠它找到本插件）。发布到应用商店后 id 会变，两边的 id 要一起改。
- Chrome 登录账号后可能同时有「本地」和「账号」两套书签，插件用找到的第一个「其他书签」（未验证这种情况）。
